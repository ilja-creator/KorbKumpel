Registrierung

Um alle Features unserer Website nutzen zu können, registrieren Sie sich, dabe müssen Sie folgende Punkte beachten:

  • E-Mail-Adresse: Bitte geben Sie eine gültige, aktive E-Mail-Adresse an! Ansonsten werden Sie keine Bestätigungsmail erhalten können und Ihr Account wird nicht freigeschalten!
  • Benutzerinfo: Bitte wählen Sie hier einen der Tags aus. Wenn Sie kein Entwickler sind oder Informationen des Administrationsteams erhlaten haben, wählen Sie Standard-Benutzer.
    Falls Sie ein Konto mit dem einer/s anderen verknüpfen wollen, wählen sie Mitnutzer. Jedoch muss die andere Person als normaler Nutzer registriert sein. Diese Funktion ist auch mit mehreren Mitnutzern möglich, sofern immer eine Person als "Hauptnutzer" gemeldet ist.
  • Wenn Sie alle Daten eingegeben haben, drücken Sie Registrieren. Sie werden in Kürze auf die angegebene Adresse eine E-Mail erhalten.
  • Bei Fehlermeldungen, wie Bitte geben Sie eine gültige E-Mail-Adresse ein! überprüfen Sie Ihre Eingabe. Eine Mail-Adresse kann bspw. korb-kumpel@email.com sein.

Passwortanforderungen:

Damit sich fremde Personen nicht so leicht Zugang zu Ihrem Account verschaffen können, haben wir folgende Passwortanforderungen zur Sicherheit Ihres Konto:

  1. Passwortlänge: Ihr Passwort muss mindestens 8 Zeichen lang sein.
  2. Zeichenvielfalt: Ihr Passwort muss mindestens jeweil einen:
    • Kleinbuchstaben
    • Großbuchstaben
    • Zahl
    • Sonderzeichen
    enthalten.
  3. E-Mail-Ähnlichkeit: Ihr Password darf keine Elemente Ihrer E-Mail-Adresse beinhalten!

Bei weiteren Fragen, wenden Sie sich bitte an das KorbKumpel-Entwicklungsteam!
